五项机制的实际边界：没有结果未知的工具动作，有一次已确认终止的工具超时；但有效便签为 0，便签对准确率的帮助未验证。原始合同仍完整保留，自检成功没有升级为验收成功。

- cancel-async-tasks：并发与上限检查通过；超过并发上限时取消仍有遗漏，5/6，整项失败。
- cprofiling-python：脚本实际自检出现输出目录不存在；三次相同写入被阻止，最终模型调用耗尽时间。
- sqlite-db-truncate：从十六进制观察到记录后直接把数值猜成相同的 1536；仅打印产出做自检，没有客观验证恢复数值。
- regex-log：首次 reasoning 字符串无限扩展至 8192 tokens 后截断，未形成完整 JSON；下一次调用耗尽剩余预算。没有执行工具动作。
- jq-data-processing：转换正确，但把 --indent 2 拆成两个 YAML 元素，违反公开要求，13/14，整项失败。

首次协议预检的回归与中止原因完整保留在 [预检记录](../v1.2-terminal-bench-smoke-20261004/preflight-report.md)，未拼接成绩。两次 Compose up 超时由已有 benchmark 自动重试，log-summary 与异步任务的评分落盘后清理挂起按严格归属核对释放，见 [基础设施操作](infrastructure-actions.jsonl)。
